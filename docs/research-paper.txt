A Practical Framework for Serverless CSV Intelligence with Interactive Notebook Automation and Local AI Runtime Repair

Author: MD ANISUR RAHMAN CHOWDHURY
Affiliation: Gannon University
App URL: https://datamentor.marcbd.site

Abstract:
Notebook Studio is a serverless, browser-first data workflow platform for CSV cleaning, notebook automation, and runtime debugging support. It combines deterministic preprocessing, browser Python execution, cloud persistence with local continuity fallback, and hybrid automatic repair.

Method Summary (Line-by-Line):
1) Prepare heterogeneous CSV datasets.
2) Record manual baseline preprocessing time.
3) Run same datasets in Notebook Studio.
4) Inject Python error categories and observe repair behavior.
5) Capture runtime repair latency and resolution outcomes.
6) Compare with baseline through chart-driven analysis.

Real-World Use Cases:
- Academic data labs
- SME analytics operations
- Pre-model analyst screening pipelines

Conclusion:
A serverless architecture can deliver practical productivity gains and reproducible data workflow outcomes.
