# GitHub Pages Publish Guide (for this repo)

## 1. Open Repo Settings
- Go to your repository on GitHub.
- Click **Settings**.
- Click **Pages** in the left menu.

## 2. Set Build Source
- Under **Build and deployment**:
  - Source: **Deploy from a branch**
  - Branch: **main**
  - Folder: **/docs**
- Click **Save**.

## 3. Wait for Publish
- GitHub will build and publish automatically.
- Your site URL will be:
  - `https://ANIS151993.github.io/Notebook-Studio/`

## 4. Verify Main Pages
- Research portal home:
  - `https://ANIS151993.github.io/Notebook-Studio/`
- Research paper:
  - `https://ANIS151993.github.io/Notebook-Studio/research-paper.html`

## 5. Update App Button (if needed)
- In `docs/index.html` and `docs/research-paper.html`, edit the `Use Web App` button URL.
